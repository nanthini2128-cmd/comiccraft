# ComicCraft - AI Comic Story Creator 🎨

ComicCraft is an AI-powered web application built for TNSDC / Naan Mudhalvan Skill Wallet. It uses Gemini AI models to generate comic story scripts, scene descriptions, and image prompts based on user input.

## Features
- Custom story generation using Gemini AI
- Panel layout configuration (2 to 6 panels)
- Multiple art styles (Manga, Marvel, Cartoon, Pixel Art)

## Tech Stack
- Python
- Streamlit
- Gemini API (`google-genai`)

## How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run app: `streamlit run app.py`
